Ваш автомобиль. Ваша история. Ваши данные.
Здесь объясняем, как 13MILL обращается с информацией.

1. Какие данные используются

Вы можете сохранить марку и модель автомобиля, госномер, VIN, пробег, историю обслуживания, детали, расходы и адреса сервисов. Эти сведения нужны для работы вашего журнала обслуживания.

2. Где хранятся данные

Данные журнала сохраняются локально на устройстве. В текущей версии нет аккаунтов и собственного сервера для хранения вашей истории.

Системные резервные копии зависят от настроек устройства и сервисов Apple.

3. Передача другим сервисам

Если вы выбираете поиск адреса в Apple, Google или Яндекс Картах, приложение передаёт адрес выбранному сервису. Дальнейшая обработка регулируется политикой этого сервиса.

В текущей версии приложения нет рекламных SDK, сторонней аналитики и отслеживания пользователей.

4. Удаление информации

Вы можете удалить сервисную работу или автомобиль внутри приложения. При удалении автомобиля удаляются связанные работы и детали. Восстановление удалённых записей внутри приложения не предусмотрено.

Удаление данных из системных резервных копий регулируется настройками соответствующего сервиса.

5. Этот сайт

Страница размещена на GitHub Pages. При её посещении GitHub может обрабатывать технические данные соединения, включая IP-адрес, в целях безопасности. Это отдельно от хранения вашего журнала в приложении.

6. Разработчик и контакты

По вопросам работы приложения и конфиденциальности можно связаться с разработчиком.
